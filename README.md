# 부산진구 수호런

부산진구 명소를 달리는 러너 게임 모음 (시연본).

- `index.html` — 명소 선택 첫 화면
- `jeonpo/` — 전포 수호런 (전포카페거리 · 가게 쿠폰 · 시즌 경품 스탬프 투어)
- `wallet/` — 내 쿠폰함 (가게에서 사장님이 PIN을 넣어 사용 처리)
- `admin/` — 쿠폰 관리 (운영자 화면, 시연용 비밀번호 `suho2026`)
- `common/sites.js` — 명소·시즌·참여 가게·쿠폰 혜택·PIN 설정 (여기만 고치면 됨)
- `server/apps-script.gs` — 정식 운영 때 쿠폰·응모를 구글 시트 한곳에 모으는 서버 코드

### 다른 제안용 데모 (이창헌)

- `cltoo/` — CLTOO RUN 러닝 게임 데모 (러닝 브랜드 제안용, 파일 하나로 동작)
- `zombie/` — 태종대 좀비런 웹게임 데모 (파일 하나로 동작)

시연 버전은 쿠폰과 응모 정보가 각 기기(브라우저)에만 저장됩니다.
`common/sites.js` 의 `endpoint` 에 Apps Script 웹 앱 주소를 넣으면 모든 기록이 한곳에 모입니다.

게임 속 가게와 쿠폰 혜택은 시연을 위한 가상의 예시입니다.

## 정식 버전 확장 계획 (메모)

- 시간대 맵: 아침 → 점심(붐비는 사람들, 런치 할인 팻말) → 저녁(버스킹, 맥주) → 밤(불꽃놀이) → 새벽(아무도 없는 질주런)
- 이벤트 스테이지: 동천 헤엄(지금 있음), 캡슐 뽑기(지금 있음 · 스테이지당 최대 1번, 낮은 확률로 이벤트 가게 스페셜 쿠폰)
- 참여 가게: 구하는 가게(퍼펙트 쿠폰) + 캡슐 뽑기 이벤트 가게(스페셜 쿠폰)를 `common/sites.js`에서 늘려 가며 운영
